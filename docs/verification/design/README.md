# Native Flutter visual references

Native Flutter widget goldens are visual references, not device screenshots or persistence proof. The frozen M02 images include the synthetic-preview label. M05 images render functional screens with a disposable synthetic SQLite fixture; they do not represent a user's practice. No private media, participant data or external image service was used.

See the [preview harness](../../../design_preview/README.md) and [screen contract](../../SCREEN_DESIGN.md) for layout/state/motion rules. `goldens/` holds 225 generated references (224 matrix cases plus one simulated-keyboard case): ten screens and four recovery states × four viewport sizes × two themes × two text scales, plus the keyboard case. `ARTIFACTS.json` records path, SHA-256, provenance and review status after image review. The baseline checker accepts only PNGs in this exact directory whose hashes match that manifest; new/changed binaries require review.

M05 adds 28 separately named `m05_*.png` references: category/setup/list/detail/qualitative goal/measured goal/exercise × two themes × phone 1×/compact 2×. Tests exercise full form scrolling and pinned Save reachability. M02's 225 files remain unchanged. Human/agent visual inspection is sampled, with exact files in each report/manifest; automated layout/golden comparison covers all cases. The goldens use SDK Roboto/MaterialIcons on the recorded macOS/Flutter renderer; production uses OS typography. Actual native widget frames live in [native](../native/ARTIFACTS.json), with physical/simulator and synthetic-store distinctions. These references are not media-playback, store or user-research evidence.

M06 adds 32 functional practice references: setup/running/paused/recovered/manual/journal/failure/saved × light/dark × phone1×/compact2×. They use real SQLite-backed screens and an injected deterministic clock, with full action/scroll checks. Sampled visual review improved pinned Start, readable long-name selection and saved-time hierarchy. Native real-clock evidence remains separate; see [M06](../M06.md).
