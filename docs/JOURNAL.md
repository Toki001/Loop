# Practice reflection and journal

M07 local journal acceptance is verified. [M07 results](verification/M07.md), [ADR-017](adr/ADR-017-session-journal.md) and the owner-directed [visual revision](adr/ADR-018-expressive-native-design.md) control actual status. Later media, trends, reminders and ownership/release gates remain separate.

Finish pauses the foreground clock and opens a reflection screen. Notes, What got easier, next step, effort and readings are optional. Save and finish is the deliberate completion action; leaving preserves the unfinished entry. Discard is confirmed. Blank reflection does not prevent completion or imply improvement. Manual duration/date require explicit confirmation; journal-only entries deliberately contribute zero seconds.

The journal repository completes the session and its clock checkpoint, existing exercise snapshots, reflection, validated readings and draft removal in one SQLite transaction. Failed writes retain the draft. Identical retries return the existing ID; a lost response after a committed Finish cannot create a second record, move its date or recreate a finish draft. Different saved values require an explicit amendment. Timed duration stays intact; manual amendments preserve manual provenance and require confirmation when duration/date change.

Readings retain immutable definition/version/unit and explicit source. Entered values are self-reported. Numeric values must be finite and respect their scale; counts and 1–5 ratings use whole numbers, percentages use0–100. Signed custom numeric units are permitted without pretending higher is better. Text and done/not-done observations retain their meaning. Effort is optional1–5 self-rating, separate from ability. Creating a reusable measure does not add a reading until the user selects and saves one. One reading per definition per session is supported; attempts/repetitions are not a hidden series.

Today and Skill Detail show actual recent completed records. The activity summary counts completed sessions and sums recorded seconds, including manual durations; journal-only entries count as entries with zero seconds. It does not score skill or infer improvement. The full journal sorts by finish date descending and stable ID; filter by skill (including archived), local date range and saved exercise title. Date bounds convert local calendar midnights to UTC, including23/25-hour DST days. Stored wall times have SQLite second precision. Dates display in the current device timezone, which is explained in the UI.

Session detail shows the persisted source, active time, reflection, exercise snapshots, metric values/method/version and revision/update metadata. Edits use optimistic revisions. A stale draft stays available while the user reviews the current record. Confirmed deletion removes dependent metadata and queues media cleanup. Immediate10-second Undo is offered for metadata-only sessions; it restores stable IDs atomically and can fail safely if parents disappear or IDs collide. No undo promise is made for deleted files.

Schema5 adds an optional What got easier column and dependent versioned JSON drafts without rebuilding sessions. Raw drafts retain unfinished numeric text rather than treating it as an observation. Notes/easier fields allow100,000 code units each, next step10,000, up to100 readings and a bounded500,000-character form representation. The application-owned600ms draft writer flushes on navigation, lifecycle interruption and Save. Bootstrap drains it before closing SQL. Failed writes show a retry state; leaving is refused when the latest staged content cannot be saved. No claim is made that a process kill can preserve a keystroke before its debounced write completes.

All fixtures live in tests. Native workflows create only marker-owned UUID stores, guard the normal journal hash, assert separate native PIDs on reopen and remove only their synthetic store. Widget goldens and native frames are labeled separately from normal product OS screenshots. No account, remote service, additional OS permission, application key or dependency is introduced by M07.
