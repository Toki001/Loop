# Practice clock, interruption and manual provenance

M06 local acceptance is verified; [M06 results](verification/M06.md) determine the actual gate. [ADR-016](adr/ADR-016-practice-clock.md) records the design. No performance, physical iPhone or release claim follows from this document.

The application owns one serialized practice engine. Native lifecycle observation is initialized before routing. A `Stopwatch` counts foreground segments only; the UI updates at 1 Hz while running and stops ticking when paused. Inactive, hidden, paused and detached events synchronously freeze elapsed time, then queue a durable pause. Resume is always deliberate. Start/Resume rechecks foreground after storage I/O; rapid taps cannot create a second timer or completion. A plan is optional guidance, never recorded practice time or a countdown limit.

Schema v4 adds `practice_checkpoints`, dependent on session identity, with accumulated milliseconds, optional planned seconds, manual draft duration/date and checkpoint UTC. The same repository transaction writes session/revision and clock state. Display/analytics retain floored total `activeSeconds`; fractions survive all pauses before final flooring. The five-second checkpoint cadence mitigates hard-kill loss, but storage stalls can extend the unsaved interval. Recovery uses only durable data, pauses any previously running record, and explains possible loss since the last checkpoint. It never estimates background time from dates. Legacy drafts without checkpoints preserve their recorded seconds; multiple older drafts remain individually recoverable.

Practice setup accepts an active skill, optional exercise snapshots and a 1–180 minute plan or no target. Names remain fully readable in a native scrollable skill picker. Start stays reachable while optional content scrolls. Active practice exposes Pause/Resume, a deliberate Finish confirmation and confirmed Discard. Notes are editable while paused and save explicitly, on leaving or on lifecycle interruption. Automatic checkpoints keep human Pause available while I/O waits. A failed clock write stops accrual, retains elapsed time in memory and offers retry; a restart can recover only the last durable checkpoint. No screen timeout override, wake lock, background audio/task, account or permission is used.

Manual practice has a separate source, entered minutes plus optional seconds (at least one second, at most seven days), local date and explicit confirmation. It records actual active time entered by the user. The finish time uses current local time on the chosen date; start is inferred by subtracting the entered duration, not instrumented. Journal-only intent deliberately records zero seconds and is labeled accordingly. Duration/date/note drafts can be saved or preserved on background; completion is atomic and repeated identical Save is idempotent. Discard ignores invalid unsaved draft fields. Clock corrections do not change elapsed time; if wall time moves before the timed start, the SQL history end is clamped to start and an explicit clock-change explanation is retained.

A persisted summary is readable by stable session ID and shows duration/source/date, selected exercise titles and note. Reflection prompts, effort, readings, editable history and timeline remain M07. Media/reminders/export remain later milestones. No fixture enters retail startup. Native tests use a strict marker-owned UUID substore, verify the normal journal hash, and remove only their owned synthetic data. Native widget captures are identified separately from OS screenshots.
